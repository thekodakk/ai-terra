# Küçük hata avı

`hesap.py` içindeki ortalama işlevinde kasıtlı bir hata var.

Çalışma klasörü projects ise test komutu:

```powershell
python -m unittest discover -s ornek-proje -v
```

Terra'ya şunu söyleyebilirsin: "ornek-proje dosyalarını oku. Testleri çalıştır,
hatayı düzeltmek için değişikliği göster, sonra testleri yeniden çalıştır."

Bu klasör yalnızca deneme projesidir.
